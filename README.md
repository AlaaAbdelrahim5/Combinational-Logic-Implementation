# Combinational Logic Implementation

Transistor-level implementation of combinational logic circuits using Microwind.

## Project Overview

This repository contains Microwind layout files (`.MSK`) for VLSI designs focused on combinational logic.

The work includes:
- CMOS layout implementation of logic gates/functions
- Design rule validation (DRC)
- Practice with lambda-based VLSI layout constraints

## Tools

- Microwind
